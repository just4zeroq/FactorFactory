# 25 · 按语义族补的加密原生因子

> **准入口径变更**：前面几批因子是「有实测才收」（`docs/23`、`docs/24`），这一批改为
> **只要求加密语义清楚、且属于当前因子池没有的族**。IC / IR 只作描述，不作门槛；
> 因子能不能进组合，仍由 verdict 的 FDR + DSR + 成本闸裁决。

内置因子池 **46 → 59**。新增 13 个，全部只使用已注册的 34 个算子，不引入新原语。

## 1. 为什么改口径

`docs/24` 用「|IC| ≥ 0.03 + 逐年同号」筛出 9 个 qweave 因子，但那套口径会系统性偏向
**已经存在的低波动、短反转族**：同一件事换窗口就能刷出一个「新因子」，而真正缺的族
（事件时间、尾部形态、资金费期限结构）因为 IC 不高被挡在门外。

对加密市场更合理的问法是：**这个维度在现有池子里有没有代理变量？** 没有就补，
至于它当期有没有 IC，交给 verdict 判。先保证搜索空间覆盖得住，再谈筛选。

## 2. 新覆盖的族

| 族 | 新增因子 | 加密市场为什么需要 |
|---|---|---|
| 事件时间 | `days_since_high60` `days_since_low60` | 7×24 交易没有收盘竞价，「距前高几天」是连续量；久盘不破前高是趋势衰竭的常见前兆 |
| 高阶矩 / 尾部 | `ret_skew20` `ret_kurt20` `ret_mad20` | 收益厚尾且左右不对称（上涨彩票、下跌踩踏），std 只看二阶矩；MAD 不受极端值污染 |
| 趋势斜率 | `trend_slope20` | `mom20` 量走了多远，`trend_r2_20` 量走得多直，斜率量走得多快，三者不是一回事 |
| 趋势残差 | `trend_resi20` | 偏离线性趋势后的短期回归；首次启用 `resi` 算子 |
| 滤波趋势 | `ema_trend10_30` | 双 EMA 差，对日线噪声更钝、对慢牛更敏感，与简单动量的权重结构不同 |
| 波动率状态 | `vol_of_vol20` | 加密常见「平静期突然转震荡」，二阶矩本身也在变 |
| 方向命中率 | `up_day_ratio20` | `sign(ret)` 的 20 日均值，只看方向不看幅度；同样涨幅，一根大阳线与十根小阳线不同 |
| 资金费期限结构 | `funding_curve21_7` | 长窗口均值减短窗口均值，量的是曲线陡峭度；`funding_carry*` 量水平、`funding_delta` 量一阶差分 |
| 持仓量短周期 | `oi_change5` | 与已有 `oi_change20` 是不同时间尺度，按 5 日前水平归一才能跨币比较 |
| 拥挤度共动 | `oi_funding_corr10` | 持仓量与资金费同步上行 = 加杠杆且付高价，是股票因子库里没有的原生变量 |

## 3. 实现要点

- `ts_argmax` / `ts_argmin` 返回的是**窗口起点起算的 0 基索引**，所以「距前高天数」
  写成 `59 - ts_argmax(high, 60)`，不是直接用 argmax（那样方向正好反）。
- `trend_slope20` 除以 `close`，把「每 bar 价格变化」变成「每 bar 收益率」，跨币可比。
- `oi_change5` 除以 `ref(open_interest, 5)`； `trend_resi20` / `vol_of_vol20` /
  `oi_funding_corr10` 按经济方向取负（偏离趋势、波动不稳、多头拥挤都视为风险）。
- 依赖 `funding_rate` / `open_interest` 的三个因子会被 `_FUTURES_ONLY_FIELDS` 自动
  拦在现货计划外，不需要在计划里额外声明。

## 4. 验证

- `tests/test_v5_v2_factors.py` 新增 4 项：距前高的天数（argmax 方向）、斜率除以价格的
  闭式解、上涨占比只看方向、13 个因子在九字段合成面板上都能走生产求值路径。
- 全部 897 项测试通过。

## 5. 已知限制

- 本地 `open_interest` 数据覆盖很低（约 180 个有限格），`oi_change5` 与
  `oi_funding_corr10` 目前只能验证求值路径，不能验证统计表现；补数据后自然生效。
- 新增因子没有逐个测 IC，因此**不要**把它们直接塞进 `prior_pool` 当「已知答案」。
  它们的作用是扩大搜索空间的覆盖度；是否值得进库由 evidence → verdict 决定。
